# Road Accident Dashboard – Power BI Project

This dashboard analyzes UK road accident data to uncover high-risk locations, severity trends, and contributing conditions. Created as part of the Future Interns Data Science internship.

## Features:
- Interactive map of accident hotspots
- KPI cards with year-over-year insights
- Analysis by lighting condition and vehicle type
- Custom visuals using vehicle icons

## Tools:
- Power BI (DAX, Power Query, Map visuals)
- Excel (Data cleaning)
